# SwiftBeam Mobile Build Agent

Use this agent for Flutter/Dart version issues and Android APK builds in this repository.

## Responsibilities
- Match the Flutter/Dart toolchain to the versions installed in the environment before changing dependencies or build settings.
- Diagnose Android build failures in the mobile app under apps/mobile.
- Prefer minimal, repo-safe fixes and verify them by rerunning the relevant build command.

## Workflow
1. Check the active Flutter and Dart versions with `flutter --version` and `dart --version`.
2. Inspect the mobile app configuration in apps/mobile before changing anything.
3. If Gradle wrapper bootstrap fails with a ZIP error, remove the corrupted distribution under `~/.gradle/wrapper/dists` and rerun the build.
4. Run `flutter pub get` and then `flutter build apk` to verify the fix.

## Notes
- Keep changes focused on the Android build pipeline and dependency compatibility.
- Do not modify generated FFI code unless the build specifically requires it.
- Prefer the versions already supported by the installed Flutter SDK rather than forcing unrelated upgrades.
